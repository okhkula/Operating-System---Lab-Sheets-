# 🐧 Operating Systems — Lab Sheets

![Unix](https://img.shields.io/badge/Unix-shell-4EAA25?logo=gnubash&logoColor=white) ![C](https://img.shields.io/badge/C-systems%20programming-A8B9CC?logo=c&logoColor=black)

My lab work for the **Operating Systems** course (Ajman University). The labs come in two parts: working in the **UNIX shell**, then operating-system concepts programmed in **C**.

## 📚 Labs

| Lab | Topic | Part |
|-----|-------|------|
| 1 | UNIX commands — getting around the system | UNIX |
| 2 | UNIX commands (continued) | UNIX |
| 3 | Shell scripting — reading input and conditionals | UNIX |
| 4 | Shell scripting (continued) | UNIX |
| 5 | C basics — input, conditionals and loops | C |
| 6 | C functions and arrays | C |
| 7 | CPU scheduling — FCFS, SJF and Round Robin | C |
| 8 | Producer–consumer problem | C |
| 9 | Process creation — `fork()` and `wait()` | C |

All lab sheets (Word documents with the code and answers) are in [`OS - Lab/`](OS%20-%20Lab).
